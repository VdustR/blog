# VDUSTR

Personal technical writing built with Astro Starlight.

## Development

```sh
pnpm install
pnpm dev
```

The site is served under `/blog/` in production. Jigmo is delivered as a
Unicode-range webfont through `@vp-tw/cjk-web-fonts-jigmo`; Victor Mono is loaded
from Google Fonts for code.
