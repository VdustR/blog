# VDUSTR

Personal technical writing built with Astro Starlight.

## Development

```sh
pnpm install
pnpm dev
```

The site is served under `/blog/` in production. HanaMin is delivered as a
Unicode-range webfont through `@vp-tw/cjk-web-fonts-hanamin`; Glow Sans TC
Condensed provides Regular and Bold body text; Victor Mono is loaded from Google
Fonts for code.
